# Auto-Marksheet-Generator

An automated Python pipeline that eliminates the manual effort of navigating academic portals by scraping student grading data and generating formatted PDF marksheets instantly.

## Features
*   **Secure Authentication:** Automates session handling and login payloads.
*   **DOM Parsing:** Extracts raw tabular grade data from the portal using BeautifulSoup.
*   **PDF Compilation:** Wraps the scraped HTML into a clean, formatted, and downloadable PDF report.

## Tech Stack
*   Python 3
*   Requests
*   BeautifulSoup4
*   PDFKit

## Note for Evaluators
**⚠️ Network Restriction Disclaimer:** The target academic portal (IIT Kharagpur ERP) is heavily restricted to the university's internal campus network and requires active student credentials to load. External execution of this script will result in an access denial or timeout.
